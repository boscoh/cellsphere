# Cell

A Vue 3 + Three.js interactive simulation: bacteria grazing on the surface of a
solid opaque sphere. Each bacterium is an elongated capsule with a thin
flagellum tail that drives its (highly viscous) motion. The sphere is covered in
clumped food that the bacteria eat to grow.

## Features

- **Opaque sphere** — bacteria and food live on the front surface; the solid
  sphere occludes anything on the far side
- **Bacteria** — capsule-shaped bodies (tube with rounded ends), oriented along
  their direction of travel, with per-cell tail variation
- **Flagellum tails** — thin, multi-wave "whisker" tails whose beat rate and
  amplitude are **coupled to forward drive** (slow bacteria beat slowly;
  tails off = no motion)
- **Food distribution** — thousands of tiny, muted specks scattered in uneven
  clumps across the sphere
- **Chemotaxis & grazing** — a bacterium senses local food concentration and
  only turns toward food when the gradient is **strongly peaked**; it slows
  **gradually** with concentration until it nearly stops inside a clump
- **Growth** — eating grows the bacterium in length (fixed width) up to at most
  **2× its starting length** (a mitosis-ready cap)
- **High viscosity** — heavy linear drag and a separate **angular drag** mean
  bacteria stop quickly when their tail stops, and rotation is slow (it must be
  generated by contact kicks and chemotaxis, like swimming in molasses)
- **Soft collision physics** — bacteria repel via a mass-weighted spring; contact
  uses accurate **capsule–capsule** distance, and rotation only comes from those
  real contacts
- **Orbit camera** — drag to orbit, scroll to zoom

## How it works

The whole simulation lives in `src/App.vue`.

### Sphere surface model
Bacteria and food are constrained to the surface of a sphere of radius
`SPHERE_RADIUS` (entities rest at `SURFACE = SPHERE_RADIUS + 0.06`, just above
the shell so they aren't z-fighting it). There is no boundary — the surface is
closed (a periodic domain).

- **Bacteria** store a surface `pos` (Vector3), a tangent `vel`, a tangent
  `heading`, an angular `headingRate`, and per-cell tail traits.
- Each frame (`animate`): chemotaxis adds a turn torque (gated by a strong
  gradient heading), angular drag damps `headingRate`, the heading is integrated
  about the surface normal, thrust is applied along the heading, linear drag
  removes velocity, and the position is re-projected onto the sphere.

### Tail-coupled propulsion (linear)
- `d.drive = power * d.slow`, where `d.slow ∈ [GRAZE_RATE, 1]` is the smooth
  concentration slowdown.
- Forward thrust uses `THRUST * drive`; the tail's beat frequency and amplitude
  also scale with `drive` (slow bacteria beat slowly; tails off → `drive = 0` →
  no tail motion and no forward motion).
- High `DRAG` bleeds velocity, so a cell halts fast when the tail stops.

### Viscous rotation (angular)
- Rotation is lazy: it is driven by an *angular velocity* `headingRate` with a
  heavy `ANG_DRAG`, so it builds only when a force maintains it.
- Two sources of turn torque: **contact kicks** (`deflectHeading` on a real
  capsule–capsule collision) and **chemotaxis** (toward the local food
  concentration direction), which only applies when the direction is strongly
  peaked (`foodPeak > PEAK_MIN`).

### Food & grazing (spatial hash)
- Food is generated in clumps (`generateClumps`, `foodInClump`) with a sparse
  background of strays, and rendered as a single `InstancedMesh`.
- `updateFood` rebuilds a **spatial hash grid** (`GRID`) each frame so each
  bacterium only tests food in its neighborhood (not all 26,000).
- **Accurate capsule collision**: distance is measured from each food to the
  body's axis segment (heading + half-length), so food must actually touch the
  body to be absorbed.
- Food proximity accumulates a **graduated concentration** (`sum`) that sets
  `d.slow` (eases toward `GRAZE_RATE`), plus a direction (`d.foodDir`) and a
  peakedness measure (`d.foodPeak`) used for chemotaxis. Eating grows the cell
  (`GROWTH_PER_FOOD`, capped by `ABSORB_CAP` per frame).

### Collisions between bacteria
`solveCollisions` computes the true **capsule–capsule** minimum distance. On
contact it applies a mass-weighted spring impulse plus positional correction,
kicks the angular rate (so the collision visibly turns the cell), and
re-projects both onto the sphere.

## Tuning parameters (constants in `src/App.vue`)

| Constant            | Meaning                                        |
| ------------------- | ---------------------------------------------- |
| `SPHERE_RADIUS`     | Sphere radius                                  |
| `CELL_COUNT`        | Number of bacteria (225)                       |
| `FOOD_COUNT`        | Number of food specks (26,000)                 |
| `MIN_RADIUS` / `MAX_RADIUS` / `START_RADIUS` | Body length range (grow; capped at 2× start) |
| `GROWTH_PER_FOOD`   | Length gained per food eaten                   |
| `ABSORB_CAP`        | Max foods absorbed per cell per frame          |
| `WIDTH`             | Body width (fixed); length grows only          |
| `TAIL_SEGMENTS` / `TAIL_LEN` / `TAIL_AMP` / `TAIL_FREQ` / `TAIL_WAVE` | Tail shape |
| `THRUST` / `DRAG`   | Propulsion / linear damping (high viscosity)   |
| `GRAZE_RATE` / `GRAZE_GAIN` | Graduated concentration slowdown (near-stop in clumps) |
| `ANG_DRAG` / `MAX_SPIN` | Angular damping / rotation rate limit        |
| `CHEMO_ACCEL` / `PEAK_MIN` | Chemotaxis torque; min gradient strength to turn |
| `SENSE_BOOST`       | Grazing sensing radius when computing concentration |
| `GRID`              | Spatial-hash cell size for food                |

Reactive UI state: `simSpeed` (time acceleration %) and `tailsActive`.
